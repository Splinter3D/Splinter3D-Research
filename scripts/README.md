# Scripts

This directory contains the utility scripts used to build and maintain the repository.

For now, it contains a single script: `compile_to_pdf.py`, which compiles the scientific report (`report/`) into a PDF.

## Directory Structure

```text
scripts/
│
├── README.md
└── compile_to_pdf.py
```

---

## 1. `compile_to_pdf.py` — Report Builder

**Purpose:** Compile `report/main.tex` (and the sections, figures and bibliography it includes) into a single PDF, without polluting the source directories.

### What it does

- Checks that all required report files and tools (`latexmk`, `biber`) are available.
- Compiles the report with `latexmk`, automatically running `pdflatex` and `biber` as many times as needed.
- Writes everything generated by the compilation into `build/`, never into `report/`: the final PDF in `build/report/`, the intermediate files in `build/intermediate/`.
- Keeps the intermediate files (`.aux`, `.bbl`, `.bcf`, `.log`, `.toc`, ...) in `build/intermediate/` between builds, which makes rebuilds faster and errors easier to investigate. They can be removed at any time with `--clean`.
- Removes stale intermediate files left in `report/` by older builds or manual `pdflatex` runs.

### Output

```text
build/
├── report/
│   └── main.pdf      <-- the final report (only the PDF)
└── intermediate/
    └── main.aux, main.bbl, main.log, ...   (intermediate files)
```

The `build/` directory is generated automatically and must **not** be committed (it is listed in `.gitignore`).

### Requirements

- **Python 3.8+**
- **A LaTeX distribution** providing `latexmk` and `biber` (see [Installing LaTeX](#2-installing-latex)).

The script only uses the Python standard library: nothing to `pip install`.

### Usage

Run the script from where ever you want:

Example (from the repository root):
```bash
python scripts/compile_to_pdf.py [options]
```

| Option | Description |
|---|---|
| *(none)* | Build the PDF in `build/report/`; intermediate files are kept in `build/intermediate/`. |
| `--clean` | Delete `build/intermediate/` (intermediate files), keep the PDF. Does not require LaTeX. |
| `--purge` | Delete the entire `build/` directory. Does not require LaTeX. |
| `--check` | Verify project files and tools, without compiling. |

### Adding a section or a required file

If a new mandatory file is added to the report (for example a new section), add it to `REQUIRED_FILES` at the top of `compile_to_pdf.py` so that the script can detect it when missing.

## 2. Installing LaTeX

The report is written in LaTeX, so a LaTeX distribution must be installed to compile it. We use **TeX Live** (Windows, Linux) and **MacTeX** (macOS, which is TeX Live packaged for Mac).

> ### ⚠️ Special characters warning
>
> The TeX Live installer (and some LaTeX tools) does **not** handle special characters well: **accents, spaces and non-ASCII characters** in paths can make the installation or the compilation fail.
>
> - Run the installer from a simple path.
> - Install TeX Live in a simple path.
> - Keep the repository itself in a simple path too.

### Windows — TeX Live

1. Download the installer from the official page: <https://www.tug.org/texlive/> (section *Windows*: `install-tl-windows.exe`).
2. Move it to a simple path (see the warning above) and run it.
3. Keep the default installation (`full` scheme, around 7–8 GB). It includes `latexmk`, `biber`, `biblatex` and every package used by the report. The installation is long (can exceed an hour); this is normal.
4. **Close and reopen** your terminal so that the new `PATH` is taken into account.
5. Verify the installation (see [Verifying the installation](#verifying-the-installation)).

Note: `latexmk` needs Perl. TeX Live for Windows ships its own, so nothing else is required.

### macOS — MacTeX

1. Download **MacTeX** from <https://www.tug.org/mactex/> and install `MacTeX.pkg` (around 6 GB, includes everything needed).

*Lighter alternative:* **BasicTeX** (from the same page) is much smaller but contains few packages. If you use it, install what is missing with:

```bash
sudo tlmgr update --self
sudo tlmgr install latexmk biber biblatex logreq csquotes babel-english collection-latexextra
```

The `collection-latexextra` line is large and is the simplest way to avoid missing-package errors one by one.

*The alternative have to be confirmed.*

### Linux (Debian / Ubuntu)

The distribution packages are enough:

```bash
sudo apt install texlive-latex-extra texlive-fonts-recommended texlive-bibtex-extra biber latexmk
```

Or, to avoid any missing package: `sudo apt install texlive-full`.
